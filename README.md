### ストラテジーパターン
インターフェース型のメンバを持つクラスで<br>
そのインターフェースを実装する被保持側クラスを<br>
入れ替えることでメソッドの挙動を変えられるデザインパターン。

### ビルダーパターン
自身を返すメソッドのチェーンでどんどんメンバ変数を装填していくデザインパターン、<br>
オプショナルなコンストラクタ引数が多すぎる場合に使用する。<br>
メソッドチェーンで積み上げた後はBuildという名のファクトリーメソッドで生成するのが流儀らしい。<br>

### イテレーターパターン
内部にカウンタを持ち、Cのポインタのように<br>
カウンタを進めながら値を取得するデザインパターン。<br>
逐次的に値をロードできるのですべての配列をメモリに展開しなくていい。<br>PHPでは標準でIteratorインターフェースが用意されているので<br>
それを実装すればforeachにも自動的に対応可能になる。
